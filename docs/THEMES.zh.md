# 主题 — 待建的专题故事

<sub>[English](THEMES.md) · [Français](THEMES.fr.md) · [Deutsch](THEMES.de.md) · [Italiano](THEMES.it.md)</sub>

**主题**是一个可以走进去的故事：与之无关的一切淡出，时间轴只显示它的年份区间，你一站一站地走，每站弹出一张卡片。目前已上线四个——亚历山大与希腊思想、民族大迁徙、蒙古入侵、伊斯兰的形成；下面二十个是我们认为接下来最值得做的。

**投票**：每个主题都有一个带 [`theme`](https://github.com/wangyuexiang/oikoumene/issues?q=is%3Aissue+label%3Atheme) 标签的 issue，给你想要的点 👍；我们按票数顺序做，大约每周一个。**没有你想要的？** 用[主题提案模板](https://github.com/wangyuexiang/oikoumene/issues/new?template=theme.md)开一个 issue，写标题、年代和一段话就够。

## 这二十个是怎么选出来的

对大约四十个候选用了五条标准：

1. **要横跨这张图。** 这张图的本钱是从大西洋连到日本。只发生在一个现代国家内部的故事，再好也先放下。
2. **每一站都能定年、定点。** 有史料站点的路线和扩散优先；需要手绘边界的故事（伊斯兰每二十年一张的边界、奥斯曼的推进）等边界管道做出来再说。
3. **不能全是战争。** 已上线的四个有三个半是军事史。这二十个是平衡的：八个讲思想、宗教、学术和艺术，五个讲贸易和旅行，四个讲疾病和技术，三个讲帝国。
4. **一句话能让人想点开。** 每个都要有一句钩子——「欧洲因一场葬礼得救」「咖啡是跟着土耳其人的辎重进维也纳的」。
5. **要和其他主题接得上。** 玄奘从蒙古主题在中国结束的地方出发；黑死病从蒙古人留下的卡法开始；造纸术在怛罗斯（伊斯兰主题的最后一站）离开，在古腾堡门口到达。二十个是一张网，不是一张表。

落选的及原因：汉尼拔（装进《罗马兴衰》）、歌德意大利之旅（装进《贵族壮游》）、启蒙运动和大学（并入《文人共和国》和《翻译之路》）、火药和国际象棋（好玩但站点太薄）、达尔文和大航海（出了地图范围）、「蒙古的世纪」（《蒙古入侵》已覆盖）。丝绸之路提议做成常驻图层，不算故事。

## 主题是怎么运作的

1. **进入**：从「主题」菜单、搜索结果或 `?theme=<id>`。
2. **聚焦**：与故事无关的政权淡出；时间轴显示主题的年份区间，每站一个点；编年栏只列它的站点；主题卡给出标题、区间、总述和史料。
3. **行走**：← → 或点编年栏逐站移动；每站飞过去并打开卡片。
4. **退出**：「退出主题」或 Esc 回到你离开时那一年的全图。

每个主题是 `public/data/themes/<id>.json` 一个文件，在 `themes/index.json` 中登记：`{id, kind, tags, span, zoom, title:{en,zh}, subtitle, summary, source, polities:[正则…], stops:[{y, c:[经度,纬度], name:{en,zh}, text:{en,zh}, w}]}`。`polities` 指定聚焦模式下保持高亮的政权。深链：`?theme=<id>&stop=<n>`。

**不计划做**：城市徽记（128 个定制图形是一个独立的设计项目）；地图范围之外的主题；任何需要后端的东西。
